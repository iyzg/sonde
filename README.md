## sonde

I really liked Jacob Steinhardt's essay on [Research as a Stochastic Decision Process](https://cs.stanford.edu/~jsteinhardt/ResearchasaStochasticDecisionProcess.html) and decided to try to implement the ideas from that into a little CLI tool. Rewrote it in Rust.

```bash
curl -fsSL https://raw.githubusercontent.com/iyzg/sonde/main/install.sh | sh

# or with
cargo install sonde
```
