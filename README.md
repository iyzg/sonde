## sonde

I really liked Jacob Steinhardt's essay on [Research as a Stochastic Decision Process](https://cs.stanford.edu/~jsteinhardt/ResearchasaStochasticDecisionProcess.html) and decided to try to implement the ideas from that into a little CLI tool. Maybe someday I'll rewrite this in Rust.
